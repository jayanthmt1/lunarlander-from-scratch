What you are watching

Eight numbers describe the lander: where it is, how fast it is going, which way it is tilted, and whether each leg is touching. Four things it can do: fire the main engine, fire either side thruster, or nothing. Every weight starts random, and the only feedback is the score.

The first few hundred attempts all crash. Then it learns to slow its descent — and stops there, because landing is worth about +260 but hovering until the 1,000-step clock runs out is worth around +140, while crashing on a landing attempt is worth about −40. Hovering beats crashing, and the gap between hovering and landing is a few precisely-timed steps that random exploration rarely finds. So it hovers, for thousands of episodes.

Around episode 7,000 it breaks out. Press ✓ Evaluate once the curve is above the dashed line to measure it properly: that runs fresh episodes using the greedy policy — always the highest-probability action, no exploration noise — which is what a deployed controller would do. Expect ~99%.

Switch to the Faithful preset to see the version that never escapes. It is the same algorithm with 212 weights instead of 836, and it hovers indefinitely. Curiously, its sampled accuracy is just as good — it is only when you remove the exploration noise that the small network falls apart, because it was never sharp enough to run deterministically.
